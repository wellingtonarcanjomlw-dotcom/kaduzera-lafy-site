O Lafy é uma integração de música para os jogadores do servidor FiveM Kaduzera Network. A interface permite pesquisar faixas disponíveis, iniciar a reprodução e controlar o áudio dentro do jogo.

Sobre a integração

O projeto conecta a interface do Lafy a serviços de música para apresentar resultados de busca e reproduzir faixas que estejam disponíveis para reprodução. Os recursos podem variar conforme o catálogo, a disponibilidade regional e as permissões de cada serviço.

  • Projeto independente para uso dentro do servidor Kaduzera Network.
  • Busca, controles do player e modo de áudio no veículo.
  • Não afiliado, patrocinado ou endossado pelo SoundCloud ou Audius.
A disponibilidade de qualquer provedor depende da autorização e dos termos aplicáveis. Esta página não declara que uma API ou integração esteja aprovada por um serviço de música.
